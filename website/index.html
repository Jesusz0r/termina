How it works

Four moves, zero leaps of faith.

01PROMPT

Prompt the real pi TUI — not a chat wrapper

A true PTY terminal runs pi with all its providers, plan mode, and completions. The terminal stays the source of truth; Termina never replaces it.

02OBSERVE

Watch every file change stream into the IDE

The watcher pushes each disk write straight into open Monaco models — files the agent touches auto-open mid-run. No polling, no refresh, no guesswork about what it just did.

03VERIFY

Run tests in the background; the verdict reaches the agent

✓ Verify runs your test suite as a background process and delivers green or red on the agent's next turn. Inside candidate worlds the same verify runs sandboxed with network denied.

04CONVERGE

Fork any moment, rank candidates, promote the winner

Every agent action is a snapshot. Fork one into isolated candidate trees, replay the task, rank them with deterministic evidence, and three-way merge the best one back.

Guardrails

An agent with root instincts,
on a short leash.

Autonomy is only useful when it is reversible. Termina isolates everything the agent touches.

ISOLATION

OS-level sandboxes

Candidate agents run inside macOS sandbox-exec profiles: your project, your home, and the snapshot store are denied, and child processes inherit the walls. Evidence and verify workers go further — fully offline.

YOUR REPO

Zero Git pollution

All snapshots live in an app-owned bare store with read-only alternates. Your personal .git, branches, and stash are never written.

CONCURRENCY

Write leases

Main-process leases stop two writers from editing one tree during critical operations. Editors save and re-acquire before every checkpoint.

SPEED

APFS copy-on-write forks

Candidate workspaces materialize in milliseconds without duplicating node_modules. Forking feels instant because it is.

RECOVERY

Crash-proof promotion

Merges write an atomic pre-image journal before touching a byte. Kill the power mid-promote; the next launch rolls back cleanly.

PRIVACY

Everything stays local

Events, sessions, snapshots, and evidence runs live on your disk. No cloud relay, no telemetry, no account required.

Speed

Get it

Two minutes from download
to your first worldline.

Signed and notarized for macOS (Apple Silicon). Standalone AppImage for Linux x64. Ships its own Node runtime and the compiled Rust core — nothing else to install.

↓ macOS .dmg (Apple Silicon) ↓ Linux AppImage (x64) all releases ↗

First launch: open a folder, then run /login and /models in the terminal to pick your provider.

Automated install script (requires Node ≥ 22.19):

curl -fsSL https://raw.githubusercontent.com/Jesusz0r/termina/master/scripts/install.sh | sh

For contributors building Electron and the Rust core:

git clone https://github.com/Jesusz0r/termina.git && cd termina && npm install && npm run dev

The Rust core builds with cargo on first run; set TERMINA_SKIP_CORE_BUILD=1 to use a downloaded binary instead.
